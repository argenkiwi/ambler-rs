The Walk trait has step(id, state) -> Transition<Id> and a provided run loop. An implementation owns its node values in a struct and matches on an Id enum, then matches each node's Outcome with no wildcard arm. A missing edge or unknown node is therefore a compile error (verified: removing one arm gives E0004). This replaced Ambler::new(HashMap<K, Box<dyn Fn>>) with its lazy loaded cache and panic on unknown id. Cost: the match is boilerplate per walk and heterogeneous graphs built at runtime are not expressible; a walk! macro or a dyn escape hatch are deferred, not decided.
