Building ambler (Rust, edition 2024, rust-version 1.85) in .pide/Containerfile needs a C compiler even though the reqwest dependency is configured with the rustls backend (no OpenSSL). The Cargo.lock pulls in ring and aws-lc-sys (via reqwest/rustls), which compile C from source; aws-lc-rs's build uses the cmake crate. So the container installs build-essential, cmake, and pkg-config on top of the base node:24-bookworm-slim image. The Rust toolchain itself is installed via rustup at CARGO_HOME=/usr/local/cargo, RUSTUP_HOME=/usr/local/rustup (fixed paths so it works for any runtime user), profile minimal with default-toolchain stable plus the clippy and rustfmt components — the README's dev workflow runs cargo clippy --all-targets and cargo fmt --check. No project files are COPYed in; the project is mounted at /workspace. Note the committed target/ cache is from macOS aarch64, so it is not reused on the Linux image and cargo rebuilds from scratch.
