Nodes are structs like Count<U = SystemUtils> with new() and with_utils(u). Utils traits use return-position impl Future + Send instead of BoxFuture, so there is no boxing and no per-call Arc clone. Gotchas: default type params are not applied in expression position, so Count::new() must live in an impl on the defaulted type (same for the walk struct); the Node future is Send only if U: Sync and S: Send, so impls bound U: Utils + Sync; and native async-fn-in-trait is not dyn-compatible, which is why utils cannot be trait objects any more. To keep ownership of a recording mock in tests, implement Utils for &MockUtils.
