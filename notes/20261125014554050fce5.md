Generated projects depend on ambler-rs through git (xtask/Cargo.toml). Cargo finds a package inside a git dependency by reading every Cargo.toml in the repository, so a template named Cargo.toml containing an unquoted placeholder ({{extra}}) caused an `invalid key-value pair` error on every cargo command in every generated project. The build still succeeded, which made it look harmless. Keep template manifests as Cargo.toml.tmpl, and keep any placeholder that has to stay in a .toml file inside a quoted string.
