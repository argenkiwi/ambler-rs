The azk-style CLI is specified as eight walks (search, create, get, update, delete, link, reindex, help) in specs/, with a plain dispatcher in main that has no spec. A single routing walk was rejected: a Walk has one State, so it would be a union of every verb fields as Options; and shared nodes like Embed have a different successor per verb, which would force per-verb duplicate Ids. Choosing a verb is a one-off lookup, not a state transition. Shared nodes (Id Arg, Exists Check, Embed, Write Note, Index Upsert, Create Links, Usage) must keep identical snake_case state field names across specs so each is implemented once.
