Walks live in src/walks/ as part of the library crate rather than inside examples/. This allows Cargo integration tests in tests/ to import the actual walk struct and test its wiring using mock utils, avoiding duplication while keeping examples as thin, readable entrypoints. Binary targets (src/main.rs, src/bin/) and runners in examples/ simply call the walk public run() function. Standard tests/ replaces the previous pattern of embedding tests in examples with test = true in Cargo.toml.
