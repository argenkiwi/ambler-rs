Integration tests cannot import examples, and duplicating the walk in tests/ would test a copy rather than the real wiring. examples/counter.rs therefore has its own cfg(test) module driven by one Script mock implementing every node's Utils for &Script, and Cargo.toml sets test = true on the [[example]] entry so cargo test runs it. The ambler-walk skill documents this as the pattern for new walks.
