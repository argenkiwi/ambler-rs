Each walk is a library module in src/walks/<name>.rs whose public surface is only `pub type Error` (or enum) and `pub async fn run()`; State, Id and the node-owning struct stay private. Its wiring test is a #[cfg(test)] module in the same file, driven by one Script mock implementing every node's Utils for &Script, so walks and nodes follow one testing convention. A tests/ integration test was rejected because it forced pub fields and test-only constructors onto the walk, and an earlier draft ended up with the same test duplicated in both places. Runners name only ambler::walks::<name>::Error, never a node's error, so the runner snippet is the same for every walk. Note Counter::default() cannot infer the defaulted utils type params in expression position, so the walk keeps a private `impl Counter { fn new() }`.
