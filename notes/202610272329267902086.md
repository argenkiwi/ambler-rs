With ~25 azk nodes, per-node Utils traits and SystemUtils would mean dozens of near-identical impls. Instead src/utils defines narrow capability traits (Out, Stdin, Clock, NoteStore, Index, Embedder); nodes bound on the subset they need, a walk is generic over one U, and utils::System implements them all. Tests pass &Fake, which is Copy so each node can hold its own copy. Failures that the spec calls values (printed as {error}) are Outcome variants; only search and reindex index failures use StoreError as the walk Error, and run() prints it.
