A node implements Node<S> and returns Result<Outcome, Error> after mutating &mut S. Each node declares its own Outcome enum (start::Outcome::{Success, InvalidInput}); it never sees the graph id type. This replaced the TS-style Edges<K> structs of Option<K>, which let a walk silently leave an edge unwired and forced a K generic on every node. Wiring outcomes to successors now happens only in the walk, see examples/counter.rs. A terminal node uses type Outcome = (), and a node that cannot fail uses Infallible, which callers unwrap with let Ok(x) = node.run(state).await.
