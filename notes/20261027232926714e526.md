Each verb's State, Id and Walk live in src/walks/<verb>.rs beside the counter reference walk, with their wiring tests inline; only `run(args) -> ExitCode` is public. Unlike the template's `Error` + `run()` surface, azk walks report failures as `{ "error" }` JSON in state and map them to an exit code, as the specs require, so they export no Error type. src/main.rs is the only runner: it calls walks::dispatch, a plain match with no walk, as the design note decided; Cargo.toml names the binary `azk` via [[bin]] so `cargo install --path .` still installs `azk` while the library stays `ambler`. The per-verb examples/ runners were dropped in favour of the single binary, and tests still use the shared in-memory Fake in src/testing.rs (cfg(test)). Three Id enums carry #[expect(clippy::enum_variant_names)] because Id::IdArg mirrors the IdArg node and spec name, which clippy only flags once the enum is private.
