Each verb's State, Id and Walk live in src/azk/<verb>.rs, with the wiring tests beside them, so the azk binary (src/bin/azk.rs) and examples/<verb>.rs can both call azk::<verb>::run. Examples are not [[example]] test targets here: tests need the shared in-memory Fake (src/testing.rs, cfg(test)), which an example cannot see. Dispatch is azk::dispatch, a plain match with no walk, as the design note decided.
