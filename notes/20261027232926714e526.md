Each verb's State, Id and Walk live privately in src/walks/<verb>.rs beside the counter reference walk, with wiring tests inline, and export only `Error` and `run(args) -> Result<(), Error>` like every template walk. The only error that stops a verb is a bad invocation: verbs alias `pub type Error = walks::UsageError` (reindex, which takes no args, uses Infallible), and run() turns a queued usage message into Err via UsageError::check after the Usage node has printed it to stderr. Failures inside a verb (missing note, unreachable index) are still printed as `{ "error" }` JSON on stdout and return Ok, because the specs require exit 0 for them. src/main.rs is the only runner and holds the verb dispatch (a plain match, no routing walk); it maps Ok/Err to exit 0/1 itself rather than returning the error from main, which would print its Debug form after the usage line. Cargo.toml names the binary `azk` via [[bin]] while the library stays `ambler`. Three Id enums carry #[expect(clippy::enum_variant_names)] because Id::IdArg mirrors the IdArg node and spec name, which clippy only flags once the enum is private.
